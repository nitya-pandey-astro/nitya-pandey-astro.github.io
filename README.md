# Astronitya — Nitya Pandey

Personal astronomy website for Nitya Pandey, hosted with GitHub Pages.

## Preview

Unzip and open `index.html` in a browser. No setup or installation is needed.

## Content

A minimal personal astronomy website: introduction, About, Research, Outreach, Notes, and Contact. Research includes a linked collaboration list and compact first-author publication mentions. About explains the Kalpana Chawla Scholarship and Schweickart Prize recognition; Outreach names specific activities. No CV, LinkedIn, experience timeline, proposal list, observing IDs, or mentoring list.

## Photos

The homepage uses Nitya’s supplied Paranal photo, mountain-trail photo, and sunset from Paranal Observatory. Image files are unchanged.

## Add a note

In `notes.html`, add a new article below the existing poem, give it a unique `id`, and add its link to the Notes index. Keep poem lines with `<br>` and stanzas with `<p>`. Add a short homepage link if desired.

## Files

- `index.html`: homepage.
- `notes.html`: poems and future writing.
- `styles.css`: minimal responsive layout.
- `script.js`: mobile menu and navigation.
- `assets/`: supplied photographs.

GitHub Pages serves these static files from the main branch.
